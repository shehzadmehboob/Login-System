# Node.js Login System

A login/signup system built with Node.js, Express, EJS, SQL Server and JWT.

## Technologies

- Node.js
- Express.js
- EJS
- SQL Server
- bcrypt
- JWT

## Features

- User signup
- Password hashing
- User login
- JWT authentication
- Protected routes
- SQL Server database

## Setup

1. Clone the repository
2. Run `npm install`
3. Create a `.env` file
4. Add your JWT secret
5. Configure SQL Server
6. Run `node app.js`
